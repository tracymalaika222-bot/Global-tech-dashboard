# Global Technology SARL — Tableau de bord Power BI

Projet de portfolio en analyse de données, réalisé pour **Global Technology SARL** (groupe N3J, Douala) — spécialiste en automatisme, réseaux industriels/télécoms, et audit de systèmes de mesure, partenaire de Mettler Toledo.

## Aperçu

![Aperçu du tableau de bord](Screenshot%202026-09-16%20024003.png)

## Contenu du tableau de bord

- **4 indicateurs clés (KPI)** : Revenu total, Nombre d'interventions, Revenu moyen par intervention, Taux de conformité
- **4 graphiques** : évolution du revenu (courbe), répartition par ligne de service (anneau), interventions par ville (carte), revenu par secteur client (colonnes)
- **Page Constats clés** : analyse des tendances et opportunités identifiées dans les données
